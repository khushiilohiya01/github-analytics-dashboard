# DevScope 🚀  
GitHub Profile Analytics Dashboard

DevScope is a clean, responsive web application that analyzes public GitHub profiles and presents meaningful insights including repository statistics, language usage, profile scoring, and developer comparison.

---

## ✨ Features

- earch any public GitHub profile
- Profile insights (repos, stars, forks, followers)
- Profile score based on activity and visibility
- Repository analysis with sorting and filtering
- Language distribution visualization
- Recent activity detection
- Best repository recommendation
- Practical improvement suggestions
- Compare two GitHub profiles
- Copy summary to clipboard
- Export profile summary
- Light / Dark mode toggle
- Recent searches (local storage)
- Fully responsive UI

---

## 🛠️ Tech Stack

- HTML5  
- CSS3 (Custom responsive design system)  
- Vanilla JavaScript  
- GitHub REST API
